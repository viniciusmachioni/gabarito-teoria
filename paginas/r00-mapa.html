A IA propõe, o código verifica R1 · structured outputs

Gabarita — Zod valida a forma, validarExplicacao valida o significado (letras batem com o banco, não contradiz o gabarito) e tenta de novo até 3 vezes. src/lib/ai/schemas.ts, src/lib/study/explain.ts.

Citação verificada R6 · AI UX

Gabarita — o resumo de diretriz só é publicado se a citação existir literalmente no texto que o modelo leu, e a interface mostra a citação. src/lib/diretrizes/citacao.ts, src/components/aviso-diretriz.tsx.

IA fora do caminho crítico R1 · estados assíncronos

Gabarita — after() gera a explicação depois da resposta HTTP, uma trava atômica no Postgres evita chamada duplicada, e o cliente acompanha com polling. Testado com fake timers.

Humano no loop R1 · human-in-the-loop

Gabarita — toda questão extraída por IA nasce needsVerification; a fila /verificacao é priorizada pelos reportes dos alunos.

Detecção determinística, correção generativa R4 · LLM sobre resultado de ferramenta

Ally AI — axe-core detecta, o Gemini escreve a correção; agrupar as violações num payload só cortou ~60% dos tokens por auditoria. apps/api/src/services/auditService.ts, aiService.ts.

Monorepo com contrato compartilhado R3 · monorepo

Ally AI — Turborepo + pnpm, o mesmo AuditResponse no back e no front, Dockerfile que copia só os manifests pra aproveitar cache de camada.

Segurança no Server Component e no edge R3/R5 · rendering, ambientes

Gabarita — o gabarito só vai pro cliente depois da resposta; CSP com nonce emitida no middleware; Sentry por túnel, sem abrir connect-src.

Tempo real orientado a evento R4 · processamento assíncrono

Ally AI — webhook Stripe assinado → Socket.io autenticado pelo cookie JWT com sala por usuário → hook React que atualiza os créditos na hora.

Munição da sua entrevista · os dois projetos como par

Os dois projetos se completam e é assim que vale apresentá-los: o Gabarita é o produto profundo (Server Components, Server Actions, fila, observabilidade, IA validada pelo significado, humano no loop), o Ally AI é o produto de plataforma (monorepo, contrato tipado compartilhado, motor determinístico + LLM, tempo real, defesa de SSRF). Juntos cobrem a maior parte das frentes R1, R3 e R4.

Por que isso importa: numa vaga de Design Engineer / Frontend com foco em IA, a pergunta não é “você já usou LLM?”, é “o que você faz quando o LLM erra?”. Validação pelo significado, citação verificada, retry que respeita a API e fila humana são quatro respostas diferentes, e todas já estão no seu código.
